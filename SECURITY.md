# Security Policy

## Supported Versions

Currently, the following versions of Laravel Social Auto Post are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this package, please send an e-mail to **Hamza Hassan** at [hamza.hassan.dev@gmail.com](mailto:hamza.hassan.dev@gmail.com) instead of using the issue tracker. 

All security vulnerabilities will be promptly addressed.

Please include:
* A description of the vulnerability.
* Steps to reproduce the issue.
* Any possible solutions you might have.

We will acknowledge receipt of your vulnerability report and send you regular updates about our progress in resolving it. If your report results in a code change, we will gladly credit you in our changelog.

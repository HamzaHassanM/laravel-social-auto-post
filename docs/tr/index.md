# Laravel Social Auto Post

8 büyük platformda aynı anda otomatik sosyal medya paylaşımı için kapsamlı bir Laravel paketi.

## Giriş

Laravel Social Auto Post, sosyal medya gönderilerini doğrudan Laravel uygulamanızdan yönetmenizi sağlayan güçlü bir pakettir. Birleşik ve zarif bir API ile içeriğinizi Facebook, Twitter, LinkedIn, Instagram, TikTok, YouTube, Pinterest ve Telegram'a sorunsuz bir şekilde yayınlayabilirsiniz.

## Desteklenen Platformlar

- Facebook
- Twitter / X
- LinkedIn
- Instagram
- TikTok
- YouTube
- Pinterest
- Telegram

## Temel Özellikler

- **Birleşik API:** Tek bir yöntem çağrısı kullanarak platform kombinasyonlarında yayınlayın.
- **Medya Desteği:** Resimleri veya videoları gönderilerinize sorunsuz bir şekilde ekleyin.
- **Dinamik Kimlik Bilgileri:** Çalışma zamanında kimlik bilgilerini kullanarak çok kiracılı veya SaaS uygulamalarını yönetin.
- **Olay Yönelimli Mimari:** Yerel Laravel Olaylarını (Events) kullanarak yayınlama döngüsüne kancalar ekleyin.
- **Güçlü Hata Yönetimi:** Başarısız API istekleri için yerleşik yeniden deneme mekanizması.

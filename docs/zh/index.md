# Laravel Social Auto Post

一个全面的 Laravel 扩展包，用于在 8 个主要平台上同时自动发布社交媒体。

## 简介

Laravel Social Auto Post 是一个功能强大的包，允许您直接从 Laravel 应用程序在各个平台上自动管理社交媒体帖子。借助统一而优雅的 API，您可以将内容无缝广播到 Facebook、Twitter、LinkedIn、Instagram、TikTok、YouTube、Pinterest 和 Telegram。

## 支持的平台

- Facebook
- Twitter / X
- LinkedIn
- Instagram
- TikTok
- YouTube
- Pinterest
- Telegram

## 主要特点

- **统一 API：** 使用单一方法调用发布到平台的任何组合。
- **媒体支持：** 无缝上传并将图像或视频附加到您的帖子中。
- **动态凭证：** 通过在运行时注入凭证来管理 SaaS 应用程序。
- **事件驱动架构：** 使用原生 Laravel 事件跟踪发布生命周期。
- **强大的错误处理：** 针对失败的 API 请求的内置自动重试。

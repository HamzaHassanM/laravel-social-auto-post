# Laravel Social Auto Post

Un package Laravel complet pour la publication automatique sur les réseaux sociaux à travers 8 plateformes majeures simultanément.

## Introduction

Laravel Social Auto Post est un package puissant qui vous permet d'automatiser et de gérer les publications sur les réseaux sociaux directement depuis votre application Laravel. Avec une API unifiée et élégante, vous pouvez diffuser votre contenu de manière transparente sur Facebook, Twitter, LinkedIn, Instagram, TikTok, YouTube, Pinterest et Telegram.

## Plateformes Prises en Charge

- Facebook
- Twitter / X
- LinkedIn
- Instagram
- TikTok
- YouTube
- Pinterest
- Telegram

## Fonctionnalités Clés

- **API Unifiée :** Publiez sur n'importe quelle combinaison de plateformes en utilisant un seul appel de méthode.
- **Support Multimédia :** Téléchargez et attachez facilement des images ou des vidéos à vos publications.
- **Identifiants Dynamiques :** Gérez les applications SaaS en injectant des identifiants à l'exécution.
- **Architecture Événementielle :** Suivez le cycle de vie de la publication en utilisant les Événements natifs Laravel.
- **Gestion des Erreurs :** Réessais automatiques intégrés pour les requêtes API échouées.

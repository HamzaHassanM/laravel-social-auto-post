# Contributing to Laravel Social Auto Post

Thank you for considering contributing to Laravel Social Auto Post! It's people like you that make this tool such a great package for the Laravel community.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct. Please be respectful and considerate of other contributors.

## How to Contribute

### 1. Find an Issue
Before you start working on a feature or a bug fix, please check the [Issue Tracker](https://github.com/HamzaHassanM/laravel-social-auto-post/issues) to see if someone else is already working on it. If not, feel free to open a new issue or comment on an existing one to let us know you're working on it.

### 2. Fork and Clone
1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/laravel-social-auto-post.git
   ```

### 3. Local Setup
Set up the project locally for development:
```bash
cd laravel-social-auto-post
composer install
```

### 4. Create a Branch
Create a new branch for your feature or bug fix:
```bash
git checkout -b feature/your-feature-name
# or
git checkout -b fix/your-bug-fix
```

### 5. Make Changes
- Follow the **PSR-12** coding standard.
- Ensure your code does not break backward compatibility unless absolutely necessary (and discussed in an issue first).
- Add tests for any new features or bug fixes.

### 6. Run Tests
Before submitting a Pull Request, ensure all tests pass:
```bash
./vendor/bin/phpunit
```

### 7. Commit and Push
Commit your changes with clear, descriptive commit messages:
```bash
git add .
git commit -m "feat: add support for new platform API"
git push origin feature/your-feature-name
```

### 8. Submit a Pull Request
1. Go to the original repository on GitHub.
2. Click on "Compare & pull request".
3. Provide a clear and detailed description of your changes, including any related issue numbers (e.g., `Resolves #123`).

## Documentation Updates
If your changes introduce new features or modify existing ones, please ensure you update the documentation:
- `README.md` (English)
- `README_AR.md` (Arabic)
- `README_TR.md` (Turkish)
- `README_ES.md` (Spanish)
- `README_FR.md` (French)
- `README_ZH.md` (Chinese)

*(If you are unable to translate to all languages, update the English version and ask for help with translations in your PR!)*

Thank you for your contributions! 🚀

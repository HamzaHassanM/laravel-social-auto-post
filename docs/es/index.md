# Laravel Social Auto Post

Un paquete integral de Laravel para la publicación automática en redes sociales a través de 8 plataformas principales de forma simultánea.

## Introducción

Laravel Social Auto Post es un paquete poderoso que le permite automatizar y administrar publicaciones en redes sociales directamente desde su aplicación Laravel. Con una API unificada y elegante, puede transmitir su contenido sin problemas a Facebook, Twitter, LinkedIn, Instagram, TikTok, YouTube, Pinterest y Telegram.

## Plataformas Soportadas

- Facebook
- Twitter / X
- LinkedIn
- Instagram
- TikTok
- YouTube
- Pinterest
- Telegram

## Características Principales

- **API Unificada:** Publique en cualquier combinación de plataformas utilizando una sola llamada al método.
- **Soporte Multimedia:** Cargue y adjunte imágenes o videos a sus publicaciones sin problemas.
- **Credenciales Dinámicas:** Gestione aplicaciones SaaS inyectando credenciales en tiempo de ejecución.
- **Arquitectura Basada en Eventos:** Controle el ciclo de vida de la publicación utilizando Eventos nativos de Laravel.
- **Manejo de Errores:** Reintentos automáticos integrados para solicitudes API fallidas.
